# English Question Pack

Future English question modules can mirror `../fr/`.

For example:

```text
en/
├── maths.js
├── french.js
├── history.js
├── geography.js
├── languages.js
├── physics.js
├── astronomy.js
└── progression.js
```

Each file should export a function that receives the shared `q` helper and returns an array of questions.
